# Fractal Collections - Como Atualizar Schema

## Regra Crítica
**NUNCA deletar uma collection para recriar com schema atualizado.**

## Processo Correto
1. Editar o arquivo de schema diretamente no sistema de arquivos (ex: `.fractal/collections/{name}/schema.ts`)
2. Atualizar os records existentes na pasta `.fractal/collections/{name}/data/` conforme o novo schema
3. Não perder dados existentes

## Por que não deletar?
- Perde todos os records existentes
- Quebra referências de outras collections
- Mais trabalhoso recriar tudo

## Aplicação
Válido para qualquer collection do Fractal (projects, suppliers, requests, quotes, etc.)
