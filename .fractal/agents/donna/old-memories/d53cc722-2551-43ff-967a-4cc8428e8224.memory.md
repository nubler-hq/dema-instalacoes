# Lição: Diagnosticar e Corrigir JSON Quebrado em Collections do Fractal

## Contexto (2026-06-24)
Durante a análise do dashboard, notei que a página de Obras só exibia 1 obra, mas havia 3 arquivos `.customers.json` no diretório `collection`.

## Diagnóstico

### Passo 1: Listar registros via API
- Usei `ListCollectionRecords` para a collection `customers` — retornou apenas 1 registro.
- Isso confirmou que o problema não era no dashboard, mas na collection.

### Passo 2: Listar arquivos no disco
- Usei `Glob` em `.fractal/collections/customers/data/*.json` — encontrei 3 arquivos.

### Passo 3: Comparar e identificar o padrão
- Li o arquivo que funcionava (gtz-84): JSON válido com vírgulas entre todos os campos.
- Li os que não funcionavam (wise, or-ryt): ambos estavam com **missing commas**.
  - **wise**: faltava vírgula após `"slug": "wise"` e após o campo `"notes"`
  - **or-ryt**: faltava vírgula após `"slug": "or-ryt"`

### Passo 4: Corrigir
- Usei `Edit` para adicionar as vírgulas faltantes.
- Verifiquei lendo os arquivos corrigidos e depois listando com `ListCollectionRecords` — agora 3 registros retornados.

## Causa Raiz
Provavelmente erro de edição manual ou geração automatizada que pulou as vírgulas entre campos obrigatórios.

## Lição Aprendida
- **Sempre verificar**: o que a API retorna vs o que está no disco
- **Sintoma clássico**: collection retorna menos registros que arquivos no diretório
- **JSON mal formatado é silencioso**: o Fractal simplesmente ignora arquivos que não fazem parse
- **Padrão de erro comum**: esquecer vírgulas entre campos (especialmente após strings)
- **Ferramenta**: `Edit` com casamento exato de string é seguro para esse tipo de correção cirúrgica
- **Verificação**: sempre reler o arquivo e testar o list depois

## Quando Suspeitar de JSON Quebrado
- Dashboard mostra menos dados que o esperado
- `ListCollectionRecords` retorna count < número de arquivos no disco
- Um registro específico não aparece mas seus vizinhos sim
- Sem erro explícito no console — o Fractal apenas omite registros inválidos
