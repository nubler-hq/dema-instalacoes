## Regra de Dados Cadastrais

**Clientes e Fornecedores devem ter todos os dados que a planilha pede.**

### Cliente (GTZ-84, WISE, RYT, etc.)
- IE pode ser isento
- Se for isento, gravar **"ISENTO"** explicitamente
- NUNCA deixar em branco

### Fornecedor (casa de material)
- **IE é obrigatória** — toda empresa de material tem
- **Se faltar, DISPARAR WORKFLOW IMEDIATAMENTE:**
  1. Procurar no e-mail com urgência (PDF, corpo, NFe anterior, e-mails antigos)
  2. Atualizar o cadastro do fornecedor com a IE encontrada
  3. Revisar TODOS os pedidos que esse fornecedor participa
  4. Atualizar a planilha de cada pedido para incluir a IE

### Por quê?
A IE do fornecedor é informação fiscal obrigatória em qualquer pedido fiscal. O Ademar cobra esse preenchimento. Fornecedor sem IE no cadastro = retrabalho garantido + reclamação.
