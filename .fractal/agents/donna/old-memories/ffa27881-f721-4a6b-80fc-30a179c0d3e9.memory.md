# Dashboard Dema Instalações — Visão 360 de Obras, Cotações e Fornecedores

## Visão Geral

Criei um clone completo do design do Mapa de Cotação em formato React/Vite, integrando-se diretamente às collections do workspace. As principais páginas contêm:

- **Dashboard** — KPIs e cards de obras clicáveis (clicáveis)
- **Obras** — Cards e tabela; clicar em uma obra abre a visão 360 detalhada
- **Pedidos e Cotações** — Kanban por status (Pendente, Cotado, Aprovado, Enviado, Rascunho) com links para obra/fornecedor
- **Fornecedores** — Segmentados (Elétrica, Hidráulica, Misto)
- **Timeline** — Eventos em tempo real via collection `events`

## Hierarquia de Navegação

```
Dashboard (home)
 └- Obras (cards e tabela)
     └- ObraDetail (referências: pedidos + fornecedores + timeline)
         └- / voltar para Obras

Pedidos (Kanban)
 └- PedidoDetail (consultas)
     └- Obra (equivalente à mesma); fornecedor (mesmo princípio)
         └- / voltar para Pedidos

Fornecedores (segmentados)
 └- FornecedorDetail (listas de pedidos + cadastrais)
     └- / voltar para Fornecedores

Timeline / Dashboard (exibidos em cada nível)
```

### 2. Modificações de PedidosPage (`PedidosPage.jsx`)

Transformado em "Kanban" por status:

- 5 colunas alinhadas com o fluxo típico: *Rascunho → Cotado → Aprovado → Enviado → Pendente*

Características:

- **Cards** – cada card exibe número do pedido, links para obra e fornecedor, tipo, total, contagem de itens; cliquáveis para abrir o PedidoDetailPage
- **Header/TopBar** – cabeçalho duplo: tênis + subtítulo + status visual do badge
- **Validação de dados** – funções auxiliares `resolveCustomer` `resolveSupplier` para resolver nomes amigáveis da collection

### 3. Atualizado App.jsx

* Adicionada `selectedObra` + componentes de detalhes:
