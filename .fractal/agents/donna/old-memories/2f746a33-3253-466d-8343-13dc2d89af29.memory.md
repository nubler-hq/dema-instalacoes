# Dema Instalações - Email com Himalaya CLI

## Configuração
- **Ferramenta:** Himalaya CLI (IMAP/SMTP client via terminal)
- **Config:** `~/Library/Application Support/himalaya/config.toml`
- **Conta:** `dema-instalacoes` (vendas@demainstalacoes.com.br)
- **Segredos no Keychain:**
  - `himalaya-dema-instalacoes-imap` (senha IMAP)
  - `himalaya-dema-instalacoes-smtp` (senha SMTP)

## Como usar
- Todos os comandos devem usar o config padrão em `~/Library/Application Support/himalaya/config.toml`
- Os segredos (IMAP/SMTP) estão no Keychain do macOS e são acessados automaticamente
- Sempre usar `--account dema-instalacoes` ou configurar como default
