# Dashboard Dema — Arquitetura Geral

## Tech Stack
- **Framework:** React 19 + React Router DOM v7 (HashRouter)
- **Build:** Vite 6 + @vitejs/plugin-react
- **Ícones:** Lucide React v0.510
- **API:** Fractal nativa via `/api/collections/{name}/records`
- **Vite base path:** `/v/dema-instalacoes/artifacts/dashboard/`

## Estrutura
```
source/
├── index.html              # div#root
├── vite.config.js          # base + build config
├── package.json
├── dist/                   # build final
└── src/
    ├── main.jsx            # createRoot + HashRouter
    ├── App.jsx             # layout + sidebar + rotas + data loading
    ├── api.js              # cliente Fractal
    ├── design.css          # design tokens + todos os estilos
    ├── components/
    │   ├── PedidoKanban.jsx
    │   └── ObraKanban.jsx
    └── pages/ (8 paginas)
```


## Data Loading
`App.jsx` carrega no mount:
- `api.getCustomers()` → customers collection
- `api.getSuppliers()` → suppliers collection
- `api.getQuotes()` → quotes collection
- `api.getEvents(50)` → events collection (ultimos 50, ordenados por timestamp desc)
Dados passados como prop `data` pras pages. Refresh manual via botao na sidebar.
