# Dashboard Dema — API Layer (api.js)

## File Location
`.fractal/artifacts/dashboard/source/src/api.js`

## Base Configuration
- **Base URL**: `window.location.origin + '/api'`
- **Content-Type**: `application/json`
- **Custom Headers**:
  - `X-Workspace-ID: dema-instalacoes`
  - `X-Agent-ID: donna`

## Exported Functions

### `listRecords(collection, options = {})`
Generic paginated/queried list for any Igniter collection.
- `collection` — collection name (e.g. `'customers'`, `'suppliers'`, `'quotes'`)
- `options.where` — JSON string of query filter
- `options.orderBy` — JSON string of sort, e.g. `{ "createdAt": "desc" }`
- `options.take` — page size (default: 50)
- `options.skip` — offset (default: 0)
- Returns: `{ data: { items: [], total: number } }`

### `getEvents(options = {})`
Specialized event reader with `take` and `orderBy` defaults.
- Defaults: `take=50`, `orderBy={"timestamp":"desc"}`
- Returns: `{ data: { items: [] } }`

### `getCustomers()`
Shortcut for `listRecords('customers')`.
Returns: `{ customers: [] }` (unwraps `data.items`).

### `getSuppliers()`
Shortcut for `listRecords('suppliers')`.
Returns: `{ suppliers: [] }` (unwraps `data.items`).

### `getQuotes()`
Shortcut for `listRecords('quotes')`.
Returns: `{ quotes: [] }` (unwraps `data.items`).

## Data Flow
- `App.jsx` calls `Promise.all([getCustomers(), getSuppliers(), getQuotes(), getEvents()])` on mount
- Results are unwrapped and merged into a single `data` object: `{ customers, suppliers, quotes, events, loading, error, reload, lastUpdate }`
- This `data` object is passed as a prop to every page via `<Routes>`
- `reload` is a callback that re-triggers `Promise.all` and resets `loading`/`error` state
- `lastUpdate` is a `new Date().toISOString()` timestamp set after each successful load

## Error Handling
- Catches fetch errors and sets `error` state string
- Error is displayed in the UI via a red banner with retry action
- Each page independently checks `loading` and `error` from the shared `data` prop
