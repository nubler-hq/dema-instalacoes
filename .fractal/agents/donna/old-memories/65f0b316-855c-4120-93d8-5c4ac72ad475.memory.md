# Erro no DeepSeek: "Prompt must contain the word 'json'"

## Sintoma
```
Error from provider (DeepSeek): Prompt must contain the word 'json' in some form to use 'response_format' of type 'json_object'.
```

## Causa Real (segundo Felipe)
**Não é** sobre faltar a palavra "json" no prompt.  
**É** sobre o payload da tool call estar mal formatado — geralmente o parâmetro `_reasoning` (obrigatório em todas as tools) está faltando ou foi passado incorretamente.

## Como Corrigir
1. Revisar todos os parâmetros da tool call
2. Verificar se `_reasoning` foi incluído (é obrigatório em TODAS as tools)
3. Verificar se todos os parâmetros required estão presentes e com os tipos corretos
4. Tentar novamente com o payload ajustado

## Lição
- `_reasoning` não é opcional — é obrigatório em toda tool call.
- Erros de provider às vezes escondem a causa real (payload mal formatado).
- Sempre revisar os parâmetros antes de assumir que é um problema externo.
