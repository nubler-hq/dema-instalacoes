# Dashboard Dema — Design System (design.css)

## File
`source/src/design.css` — ~28KB, single CSS file without preprocessors.

## Color Palette (Warm/Light)

| Token | Hex | Usage |
|-------|-----|-------|
| `--brand` | `#a94f2d` | Primary brand color, buttons, links, active states |
| `--brand-hover` | `#933e1f` | Darker hover state for brand elements |
| `--paper` | `#fbf7ef` | Page background — warm off-white |
| `--surface` | `#fffdf8` | Card/section backgrounds |
| `--border` | `#e8e0d0` | Subtle borders and dividers |
| `--text-primary` | `#3d2817` | Main body text |
| `--text-secondary` | `#8b7a6a` | Secondary/muted text |

## Layout Components

### App Shell (`.app-layout`)
- Full viewport height, flex row
- Sidebar (260px fixed width) + main content area (flex: 1)

### Sidebar (`.sidebar`)
- Fixed 260px, full height, sticky
- Brand logo area at top
- Nav links with icons + badge counts
- Bottom section: last-update timestamp + "Recarregar Dados" button

### Metrics Band (`.metrics-band`)
- Horizontal flex row with gap
- Each `.metric-card`: small label, large bold value, optional trend

### Card Grid (`.card-grid`)
- CSS Grid: `repeat(auto-fill, minmax(300px, 1fr))`
- Each `.card`: surface background, border, rounded corners, padding, hover lift effect

### Kanban Layout (`.kanban`)
- Horizontal flex row, overflow-x auto
- Each `.kanban-column`: min-width 280px, max-width 340px
- Column header with title + count badge
- Cards stacked vertically with gap

### Tables (`.data-table`)
- Full-width, clean horizontal layout
- `th` styled with border-bottom + text-secondary
- `td` with vertical alignment
- Minimal borders, no alternating row colors

### Timeline (`.timeline`)
- Vertical line on the left
- Each `.timeline-item`: circle marker + timestamp + content card
- Icon by event type

### Supplier Grid (`.supplier-grid`)
- CSS Grid: `repeat(auto-fill, minmax(280px, 1fr))`
- Supplier card with name, segment badge, contact info

## Badge System
- `.badge` — base pill shape, small font, uppercase
- `.badge-success` — green (aprovado, finalizada)
- `.badge-warning` — yellow/amber (pendente, cotando)
- `.badge-danger` — red (atrasado, cancelado)
- `.badge-info` — blue (rascunho, estudo)
- `.badge-muted` — gray (emitido, arquivado)

## Tabs
- `.tab-bar` — horizontal flex row
- `.tab` — clickable tab item with bottom border indicator
- `.tab.active` — brand color bottom border

## Responsive
- Single breakpoint at `max-width: 900px`
- Below 900px: sidebar collapses/hides, content goes full width
- Kanban columns may stack or scroll horizontally
- Card grids go single column

## Typography
- System font stack (no custom fonts loaded)
- Headings: `--text-primary`, bold
- Body: `--text-primary`, regular weight
- Muted/secondary: `--text-secondary`, small font
- Monospace: `ui-monospace, monospace` for code/data values
