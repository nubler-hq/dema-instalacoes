## Checklist de Revisão Obrigatório

Antes de entregar QUALQUER trabalho, verificar:

- [ ] **Sem duplicatas** — listar antes de criar, verificar se registro já existe
- [ ] **Sem chamadas paralelas de escrita** — serializar SEMPRE
- [ ] **Itens de pedido sem duplicatas** — descrições iguais = consolidar quantidades
- [ ] **Planilha revisada** — colunas largas o suficiente, fórmulas corretas, sem textos fixos indevidos
- [ ] **Dados do cliente/fornecedor completos** — IE, CEP, endereços
- [ ] **Endereço de entrega vs cobrança** — confirmar se são diferentes
- [ ] **Totais conferidos** — somar manualmente e comparar com PDF
- [ ] **Status correto** — quoted, sent, approved, rejected/excluded
- [ ] **Comparação entre cotações** — verificar divergências de preços e quantidades
