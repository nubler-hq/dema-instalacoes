## Regra: NUNCA chamar ferramentas de escrita em paralelo no Fractal

Chamar create/update/delete em paralelo no Fractal causa:
- Race conditions
- Duplicatas de registros (tasks, collections records, etc.)
- Sobrescrita de dados
- Estado inconsistente

**Sempre serializar operações de escrita.** Esperar uma terminar para começar a próxima.

### Checklist antes de toda criação:
1. **LISTAR** antes de criar — verificar duplicatas
2. **SERIALIZAR** escritas — uma por vez
3. **REVISAR** antes de entregar
