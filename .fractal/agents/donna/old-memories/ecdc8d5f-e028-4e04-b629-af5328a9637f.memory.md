## Workflow de Cotação: Descobrir Número do Pedido

Quando chega e-mail de fornecedor, a ordem de resolução do número do pedido é:

### 1. Ler e-mail e baixar anexo
- Ler e-mail do fornecedor
- Ler e-mail do Ademar (pode ter contexto)
- Salvar anexo (PDF) em pasta temporária `.fractal/collections/quotes/_tmp/`

### 2. Analisar outros pedidos do MESMO cliente na collection `quotes`
- Comparar itens da cotação atual com itens de pedidos existentes
- **Se os itens batem com algum pedido existente → usar o mesmo número**
- Isso evita criar pedido novo com mesma lista de itens (= duplicação)

### 3. Se o número não está explícito e nenhum pedido bate:
- Buscar nos e-mails qual foi o último número usado para aquele cliente
- Definir o próximo número de acordo com o type (Elétrica, Hidráulica, Fixação, etc.)
- Pode ser que cada type tenha numeração independente

### Por quê?
- Evitar duplicação de pedidos
- Manter consistência de numeração
- Não precisar perguntar ao Felipe o número (automatizar)

### Detecção de duplicatas:
Sempre verificar pelo tuple: `customer + number + type + supplier + proposal` ANTES de criar um quote.

### Limpeza:
Após registrar a cotação na collection, deletar o PDF da pasta temporária `_tmp/`.
