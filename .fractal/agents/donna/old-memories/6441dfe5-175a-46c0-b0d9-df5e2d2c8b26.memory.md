# Regra: Confirmação Obrigatória Antes de Enviar E-mails

## Regra Crítica
**Sempre confirmar com o usuário antes de enviar qualquer e-mail.**

## O que confirmar
1. **Assunto** do e-mail
2. **Corpo/conteúdo** completo do e-mail
3. **Se é uma resposta** ou e-mail novo
4. **Destinatário** correto

## Processo
1. Montar o rascunho do e-mail
2. Mostrar ao usuário para aprovação
3. Aguardar confirmação explícita
4. Somente então enviar

## Nunca fazer
- Enviar e-mail sem mostrar o conteúdo primeiro
- Enviar e-mail sem confirmação do usuário
- Assumir que o conteúdo está correto sem validar

## Aplicação
Válida para todos os e-mails enviados via Himalaya CLI ou qualquer outro meio.
