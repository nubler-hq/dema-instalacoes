# Regra: Nomenclatura de Arquivos de Pedido

## Padrão Obrigatório
```
PEDIDO-{numero}-{obra}-{fornecedor}-{data}.xlsx
```

## Componentes
- `{numero}` → Número do pedido: `005`, `006`, `2105/26`
- `{obra}` → Slug da obra: `WISE`, `GTZ84`, `RYT`
- `{fornecedor}` → Nome curto do fornecedor: `PLASTICON`, `FFGUARULHOS`, `FIXAGOLD`, `SHAFT`
- `{data}` → Data no formato DDMMAAAA: `21052026`, `05052026`

## Exemplos Válidos
- `PEDIDO-005-WISE-PLASTICON-21052026.xlsx`
- `PEDIDO-006-WISE-FFGUARULHOS-21052026.xlsx`
- `PEDIDO-001-GTZ84-FIXAGOLD-21052026.xlsx`
- `PEDIDO-2105-RYT-SHAFT-18052026.xlsx`

## Por que padronizar?
- Facilita identificação rápida
- Ordem cronológica natural
- Busca por obra/fornecedor fácil
- Consistência profissional
