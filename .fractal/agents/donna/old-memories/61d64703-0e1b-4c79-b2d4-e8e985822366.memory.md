# Lições sobre Filtros e Execução de Tools

## 1. Uso de Filtros em Listagens
Ao buscar registros em collections (ex: `tasks`, `quotes`), **NUNCA** comece com filtros muito restritivos.
- **Protocolo:** Primeiro liste todos os registros (ou use filtros bem amplos) para obter o contexto geral. Só então, se necessário, aplique filtros mais específicos baseados nos dados reais encontrados. Isso evita o falso-negativo de achar que não existem dados.

## 2. Passagem de Parâmetros JSON em Tools
Ao chamar ferramentas (`fractal toolsets call`), o campo `data` aceita o objeto JSON direto.
- **Protocolo:** **NÃO** utilize `JSON.stringify()`. Passe o objeto estruturado diretamente na requisição.
