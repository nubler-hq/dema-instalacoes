# Schema da Collection `quotes` - Dema Instalações

## Decisão Arquitetural (2026-05-21)
- **Unificamos** `requests` + `quotes` em uma única collection `quotes`
- **Deletamos** a collection `requests` (`.fractal/collections/requests/`)
- **Normalizamos** com referências por ID em vez de dados duplicados

## Schema Final

```typescript
z.object({
  // Referências (IDs de outras collections)
  project: z.string(),    // ID do projeto (ex: "03be712a-263a...")
  supplier: z.string(),   // ID do fornecedor (ex: "a492b43d-cad0...")

  // Identificação do pedido
  order: z.string(),      // Número: "005", "2105/26"
  type: z.string(),       // "Elétrica", "Hidráulica", "Fixação"
  quote: z.string(),      // Número da proposta: "23876", "844.448"

  // Condições comerciais
  paymentTerms: z.string().optional(),   // "28 dias"
  freight: z.string().optional(),        // "CIF", "FOB"
  deliveryDays: z.number().optional(),   // 7

  // Faturamento (pode variar por obra)
  invoice: z.object({
    name: z.string(),   // "SMG22 Empreendimentos..."
    cnpj: z.string()    // "48.868.032/0001-30"
  }),

  // Itens
  items: z.array(z.object({
    description: z.string(),
    quantity: z.number(),
    unit: z.string(),
    unitPrice: z.number().optional(),
    totalPrice: z.number().optional(),
    notes: z.string().optional()
  })),

  // Totais
  subtotal: z.number().optional(),
  taxes: z.number().optional(),
  total: z.number(),

  // Arquivo Excel do pedido
  file: z.string().optional(),  // Path: ".fractal/artifacts/..."

  // Status
  status: z.string(),  // "quoted" | "sent" | "approved" | "ordered" | "rejected"
  notes: z.string().optional(),

  // Datas
  quotedAt: z.string().datetime().optional(),
  sentAt: z.string().datetime().optional(),
  approvedAt: z.string().datetime().optional(),
  createdAt: z.string().datetime().optional()
})
```

## Motivo
Evitar redundância de dados e complexidade desnecessária. Cada pedido é uma cotação que vira um pedido de compra — registro único, verdade única.

## Relacionamentos
- `project` → collection `projects` (ID do record)
- `supplier` → collection `suppliers` (ID do record)
