# Dashboard Dema — Pages & Routes

## Routing
- **React Router v7** with `<HashRouter>` (wraps `<Routes>` in `main.jsx`)
- All routes are defined in `App.jsx` as `<Route>` children

## Routes Table

| Route | Component | Description |
|-------|-----------|-------------|
| `/` | DashboardPage | Home: 5 KPIs + obra cards grid + PedidoKanban overview |
| `/obras` | ObrasPage | Status summary bar + ObraKanban (4-column kanban by obra status) |
| `/obras/:slug` | ObraDetailPage | Full obra detail: hero, KPIs, 3-tab panel (Cotações/Timeline/Cadastro) |
| `/pedidos` | PedidosPage | Status metrics band + PedidoKanban + full item table |
| `/pedidos/:id` | PedidoDetailPage | Order detail: hero, supplier comparison, KPI band, item table with download buttons |
| `/fornecedores` | FornecedoresPage | 4 KPIs + 3 category sections (Elétrica/Hidráulica/Misto) with supplier cards |
| `/fornecedores/:slug` | FornecedorDetailPage | Supplier detail: header, Dados (contact/address/CNPJ), Pedidos (PedidoKanban), Atividades |
| `/timeline` | TimelinePage | Events grouped by day with icon per type, relative day labels |

## Page Patterns

### Hero Section (Detail Pages)
- All detail pages (`ObraDetailPage`, `PedidoDetailPage`, `FornecedorDetailPage`) share a hero header pattern:
  - Back button (navigates to parent list)
  - Avatar/image placeholder (initials or icon)
  - Title + subtitle/type
  - Status badge (colored pill)
  - Tags/chips for related entities (obra name, supplier, engineer)
  - Action buttons row (WhatsApp, call, email, PDF/XLSX download)

### KPI Bands
- Top of most pages: a horizontal band of metric cards
- Each KPI card shows: label (small gray), value (large bold), optional delta/trend
- Examples:
  - DashboardPage: 5 KPIs → active obras, quoting obras, total quotes, total value, supplier segment count
  - ObraDetailPage: 5 KPIs → quote count, total value, supplier count, sent count, event count
  - FornecedoresPage: 4 KPIs → total, electrical, hydraulic, mixed suppliers
  - PedidosPage: metrics band with count per status

### Tab Panels
- `ObraDetailPage` uses a 3-tab panel: Cotações | Timeline | Cadastro
- `FornecedorDetailPage` uses sections: Dados | Pedidos | Atividades
