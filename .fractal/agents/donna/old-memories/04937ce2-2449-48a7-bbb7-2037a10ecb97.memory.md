# Estrutura de Pastas para Pedidos de Compra - Dema Instalações

## Estrutura Padronizada

```
.fractal/artifacts/
├── docs/
│   └── projects/
│       ├── wise/requests/              # Pedidos da obra Wise Vila Clementino
│       ├── gtz/requests/               # Pedidos da obra GTZ 84
│       └── or-ryt-paulista/requests/   # Pedidos da obra RYT Paulista
└── pedidos/                            # Pedidos gerais
```

## Nomenclatura de Arquivos
Formato: `PEDIDO-{numero}-{obra}-{fornecedor}-{data}.xlsx`

Exemplos:
- `PEDIDO-005-WISE-PLASTICON-21052026.xlsx`
- `PEDIDO-006-WISE-FFGUARULHOS-21052026.xlsx`
- `PEDIDO-001-GTZ84-FIXAGOLD-21052026.xlsx`
- `PEDIDO-2105-RYT-SHAFT-18052026.xlsx`
- `PEDIDO-001-RYT-PLASTICON-05052026.xlsx`

## Decisão
- Criar subpastas `requests/` dentro de cada projeto
- Padronizar nomes de arquivos para facilitar identificação
- Manter um registro centralizado na collection `quotes` com campo `file` apontando para o path
