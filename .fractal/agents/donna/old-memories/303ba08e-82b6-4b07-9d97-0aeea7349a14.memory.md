## Template de Planilha: Textos Fixos

### Problema
O template PEDIDO.xlsx tinha textos fixos que não variavam por fornecedor:
- "Itens de estoque em até 2 dias..."
- "Não emitir nota fiscal após o dia 25"
- "8:00 HS AS 11:00 HS E DAS 13:00 HS AS 16:00 HS"
- "NÃO SERÁ ACEITO EM HIPOTESE NENHUMA..."
- "Pedido mínimo R$ 300,00..."

### Solução
Criado campo `terms` no schema quotes com:
- `deliveryTimeframe` (prazo entrega)
- `billingNote` (faturamento)
- `deliveryHours` (horário entrega)
- `generalTerms` (termos gerais)
- `observations` (observações)

Template foi atualizado para usar placeholders `{quote.terms.xxx}`.

### Lição
Sempre verificar se a planilha gerada contém textos fixos que deveriam vir dos dados. Se sim, criar campo no schema ou avisar o usuário explicitamente.
