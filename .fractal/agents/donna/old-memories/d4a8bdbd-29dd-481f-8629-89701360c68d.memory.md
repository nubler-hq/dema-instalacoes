# Lesson

The Bash tool failures were caused by the development environment running with Bun `--hot` enabled.

## What happened
When `--hot` was active, Bash executions returned inconsistent results, including empty output, `exitCode: 1`, and malformed payloads. After removing `--hot`, the same commands started working normally.

## Impact
This caused a long debugging detour because the tool itself appeared broken, but the real issue was the Bun dev runtime mode.

## Takeaway
When Bash behaves inconsistently in this workspace, check whether Bun `--hot` is enabled before investigating the tool layer itself.
