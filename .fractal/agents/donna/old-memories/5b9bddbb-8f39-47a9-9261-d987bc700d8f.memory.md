# Constraint

If the Bash tool returns an error or an inconsistent payload, do **not** retry automatically.

## Required behavior
- Stop the current action immediately.
- Inform the user that the Bash attempt failed.
- Wait for the user to decide the next step.
- During intentional Bash tests, follow the agreed process exactly and avoid looping or adding extra commands.

## Why
This prevents repetitive retries when the environment is unstable and reduces the risk of the agent going into a self-reinforcing debug loop.

## Scope
Applies to Bash execution in this workspace, especially when diagnosing environment issues or validating tool behavior.
