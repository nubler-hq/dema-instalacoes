# Histórico de conversas do agente no Zed

## Caminho no macOS

O Zed **NÃO** guarda conversas em `~/.local/share/zed/conversations/` (caminho Linux/Windows).
No macOS, o banco SQLite fica em:

```
~/Library/Application Support/Zed/threads/threads.db
```

Arquivo único (~73 MB em 26/06/2026), atualizado continuamente.

## Schema da tabela `threads`

```sql
CREATE TABLE threads (
  id                TEXT PRIMARY KEY,   -- UUID da conversa
  summary           TEXT NOT NULL,     -- título (vazio em threads novas)
  updated_at        TEXT NOT NULL,     -- ISO 8601
  data_type         TEXT NOT NULL,     -- tipo do blob (ex.: "zstd")
  data              BLOB NOT NULL,     -- mensagens compactadas
  parent_id         TEXT,              -- thread pai (sub-conversas)
  folder_paths      TEXT,              -- caminho do projeto onde a conversa rolou
  folder_paths_order TEXT,
  created_at        TEXT
);
```

## Filtro por projeto

A coluna `folder_paths` guarda o caminho do workspace em que a thread foi aberta/rodou.
Filtrar por Dema Instalações:

```sql
SELECT id, summary, created_at, updated_at
FROM threads
WHERE folder_paths = '/Volumes/Sandbox/Sandbox/nubler/dema-instalacoes'
ORDER BY updated_at DESC;
```

⚠️ **Atenção:** muitas conversas podem estar marcadas como `/Volumes/Sandbox/Sandbox/nubler/fractal` em vez do caminho do projeto dema-instalacoes, porque a Dema roda dentro de um workspace Fractal. Para "tudo que é Dema", considerar os dois caminhos e/ou inspecionar o conteúdo do `data`.

## Como abrir e ler

```bash
DB="$HOME/Library/Application Support/Zed/threads/threads.db"

# Listar todas as conversas
sqlite3 "$DB" "SELECT id, summary, updated_at, folder_paths FROM threads ORDER BY updated_at DESC;"

# Contar por projeto
sqlite3 "$DB" "SELECT folder_paths, COUNT(*) FROM threads GROUP BY folder_paths ORDER BY 2 DESC;"

# Filtrar por projeto
sqlite3 "$DB" "SELECT * FROM threads WHERE folder_paths = '/Volumes/Sandbox/Sandbox/nubler/dema-instalacoes';"
```

O campo `data` é BLOB compactado (provavelmente zstd) — para exportar/ler o conteúdo
real das mensagens, é preciso descompactar. O usuário pediu para manter referência
dessa estrutura; implementar exportação full é trabalho futuro se necessário.

## Por que isso importa

- O Felipe pode pedir "lembra daquela conversa que a gente teve sobre X" — esta
  memória permite localizar threads relevantes rapidamente.
- O histórico é uma fonte de evidência local independente do Fractal — útil quando
  o conteúdo de uma decisão não foi capturado em memories/collections.
- Recurso valioso: ter um índice pesquisável das conversas anteriores com o agente.
